FAQ

E-invoicing vs e-reporting ?
E-invoicing : facture structurée B2B domestique.
E-reporting : envoi de données (B2C, export, international).

PPF, PDP, OD ?
PPF = portail public, PDP = plateforme partenaire, OD = opérateur (conversion / interfaces).

Glossaire

  • PPF : Portail Public de Facturation
  • PDP : Plateforme de Dématérialisation Partenaire
  • OD : Opérateur de Dématérialisation
  • Factur-X / UBL / CII : formats structurés
